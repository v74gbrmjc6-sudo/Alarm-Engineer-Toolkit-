Fault Finder

Bell tamper

Confirm whether present now. Review event sequence. Check bell tamper, cable/joints, terminals and supply during activation. Consider PSU/battery loading.

Zone tamper

Check device lid/tamper, exact wiring/resistor scheme, cable and joints, then expander input. Verify against the exact panel manual.

False alarm

Start with event log. Check device environment, contamination, temperature, mounting and wiring. Prove the diagnosis before replacement.

Battery fault

Check age, terminals, charging/PSU output and behaviour under load. One voltage reading is not enough to condemn a battery.

ATS/ARC fault

Split the path: panel → communicator → network/mobile → ARC. Check status, programming and signalling test procedure.

Calculators

Ohm's law

V = I × R · I = V ÷ R · R = V ÷ I

Approx. battery capacity

Ah ≈ load current (A) × required standby hours. Real compliance calculations must use the applicable standard/manufacturer requirements and derating.

Resistor values

There is no universal alarm resistor value. Always use the exact panel's wiring scheme.

Wireless / Ricochet

1. Device

Battery, tamper, mounting and device state.

2. Signal/path

Use manufacturer diagnostics to assess the route.

3. Building

Consider metalwork, foil-backed insulation, plant rooms and building changes.

4. Mesh

Consider the whole route rather than only the end device.

ARC / ATS

Panel → communicator

Check module power, panel programming and communicator status.

Communicator → network

Check Ethernet/Wi-Fi/mobile path and status indicators as applicable.

ARC

Confirm account details and perform an agreed signalling test under your monitoring procedure.
